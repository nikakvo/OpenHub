# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and
choose **Report a vulnerability**. Describe what you found, how to reproduce it and which
OpenHub version you used. You will get an answer, and a fixed release, as soon as possible;
you will be credited in the release notes if you wish.

## Supported versions

Only the newest release receives fixes. The built-in updater (Settings, Check for updates)
announces new versions.
